How it works

Three engines. One verdict you can audit.

01

Paste the claim and its source

A viral summary next to the announcement it came from. A recruiter's pitch next to the real posting. Paste both texts, or fetch the source straight from its link — the fetched text lands in the box for you to read first. The first pass runs on your device — your text goes to the cloud only for the deep check, and only when you are online.

02

The engines route the work

Gemini Nano extracts the checkable points on-device. Cloud Gemini via Firebase AI Logic reads for meaning when online. Deterministic code then compares every number, date and name — the facts a model should never get to improvise.

03

Read a verdict with evidence

Every point comes back supported, contradicted, or not in the source — with the source quote as evidence, a badge naming the engine that decided it, and a routing log that records every decision, including the fallbacks.

Principles

Built so a judge can check the checker.

Code decides the facts

Numbers, dates and names are compared by deterministic code — never by a model's mood. Rp 15,000,000 either equals Rp 10,000,000 or it does not.

Every verdict names its engine

Each point carries a routing badge and a latency. You always know whether Nano, the cloud model, or plain code produced the answer you are reading.

Fallbacks are stated, never hidden

If an engine is unavailable, the status panel and the routing log say so in plain words. Nothing on this page is simulated or faked — unavailable means skipped, and skipped means logged.
